**Новое**

- «Почему не скачались»: в «Загруженных» — список треков, которые не скачались, и причина у каждого (YouTube ограничил запросы — смени сервер VPN; трека нет в источниках). «Повторить все» и «Очистить».
- Альбом: тип (Сингл / Альбом / Мини-альбом), полная дата релиза, число прослушиваний Spotify у каждого трека.
- Артист: кнопки «перемешать / играть / скачать» для популярных треков.
- Очередь: число композиций и общее время в шапке, играющий трек подсвечен.
