**Тексты песен, язык, значок**

- Тексты из пяти источников, как на Android: BetterLyrics (тексты Apple Music), Paxsenix (пословные), LrcLib, KuGou, LyricsPlus (выключен по умолчанию). Настройки → Плеер → «Текст»: включение и порядок перетаскиванием.
- Пословная подсветка: если у текста есть разметка по словам, слова загораются по очереди; фоновые голоса — мельче.
- Меню текста (⋯ справа сверху): обновить, скопировать весь текст, сдвиг синхронизации на 0,5 с раньше/позже (запоминается для трека).
- Строки «synced by…», «lyrics by…» убираются.
- Настройки → Внешний вид → «Язык приложения»: как в системе, русский или английский — меняется сразу.
- Настройки → Плеер → Очередь: «Автозагрузка» и «Отключить автозагрузку в режиме повтора всех треков».
- У приложения появился значок.

Ограничения: перевода и романизации текстов пока нет.
