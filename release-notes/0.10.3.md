**Сверка с Android вживую: меню трека, настройки, артист, альбом, чат, стикеры**

- **Интеграции** — новый значок пазла в шапке (как на Android): источники музыки, Spotify, Яндекс, VK, Last.fm.
- **Настройки** разложены по экранам Android: «Внешний вид» (тема, язык, текст песни, вкладка при запуске, какие плейлисты показывать), «Плеер и аудио» (таймер сна, очередь, тон вместе со скоростью, без дублей), «Контент», «Сообщения» (быстрая реакция, уведомления), «Хранилище» (кэш картинок).
- **Меню трека «⋮»**: «Запустить радио», «Запретить», «Удалить из плейлиста / истории», «Поделиться» (ссылкой, файлом, в чат), «Контроль аудио» (скорость и тон).
- **Артист** как на Android: большое фото, жанры, «Подписаться», «Радио», «Перемешать», «Играть», подписчики и слушатели, популярные, альбомы, синглы, «Участие», похожие.
- **Альбом**: жанры цветными метками, «Играть / Загрузить / ♥», прослушивания справа у треков, «Выбрать треки» в шапке.
- **Чат**: стикеры — панель на месте клавиатуры (сетка с подписями); треки, отправленные вместе, — одним пузырём; ответ свайпом влево; меню сообщения долгим нажатием; мини-плеер в чате прячется. Сообщения приходят, пока приложение открыто.
- **Плеер**: работает «повторять один»; вместо «0 kbps» — настоящий битрейт; «Версия трека» показывает несколько вариантов от каждого источника; обложка не давит кнопки на маленьком экране.
- **Тексты** ищутся во всех источниках сразу, выбирается синхронный; подсветка точнее.
- **Библиотека**: «Композиции / Скачанные / Мой топ» — под фишкой «Локальные», поиск по библиотеке.
- **Поиск**: ссылки Spotify, Яндекса, Drxwnify и YouTube прямо в строке поиска.

Не сделано: «Слушать вместе» по комнатам, эквалайзер, Discord, аккаунт YouTube.
