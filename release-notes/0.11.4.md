**Мелкие правки по проверке экранов**

- «Афиша»: дата как «Четверг, 12 ноября» (месяц со строчной).
- «Статистика»: короткие подписи периодов — Неделя, Месяц, Год, Всё время (раньше обрезались).
- Скрытые вкладки больше не читаются VoiceOver.
- Для проверки экранов без нажатий: приложение можно запустить с переменной `DRX_SCREEN` (открывает нужный экран); на обычную работу не влияет.
