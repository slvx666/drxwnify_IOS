**Чаты открываются, вкладки переключаются плавно**

- «Вместе» → «Чаты»: список переписок с последним сообщением; нажатие открывает чат. Так же надёжно открываются друзья и «Мой профиль» (раньше нажатия внутри листаемых вкладок не срабатывали — ошибка SwiftUI на iOS 14–16).
- Переключение «Главная / Поиск / Библиотека» — плавное растворение вместо мгновенного скачка.

Зелёная рамка на экране — подсветка системного инструмента доступности, который запускался при проверке с ноутбука; убирается перезагрузкой iPhone.
